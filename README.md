# ربات تلگرام گیم سنتر

یک ربات تلگرام کامل برای مدیریت گیم سنتر با قابلیت‌های:

## ✨ ویژگی‌ها

- 🎮 **مدیریت بازی‌ها**: نمایش لیست بازی‌ها و جزئیات هر بازی
- 🏆 **سیستم تورنمنت**: ثبت‌نام در تورنمنت‌ها و مدیریت شرکت‌کنندگان
- 📊 **ثبت امتیازات**: ردیابی امتیازات بازی‌های کاربران
- 👤 **پروفایل کاربری**: نمایش اطلاعات کاربر و موجودی
- 📅 **رزرو وقت**: سیستم رزرو زمان برای بازی‌ها با انتخاب مدت زمان
- ❌ **کنسل کردن رزرو**: امکان کنسل کردن رزرو قبل از زمان شروع
- 🔔 **اطلاع‌رسانی**: سیستم اطلاع‌رسانی (به زودی)

## 🚀 نصب و راه‌اندازی

### ۱. دریافت توکن ربات

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید
2. دستور `/newbot` را ارسال کنید
3. نام ربات را وارد کنید
4. یوزرنیم ربات را وارد کنید (باید با `_bot` ختم شود)
5. توکن دریافت شده را کپی کنید

### ۲. تنظیم محیط

```bash
# نصب کتابخانه‌های مورد نیاز
pip install -r requirements.txt
```

### ۳. تنظیم توکن

فایل `.env` ایجاد کنید و توکن را در آن قرار دهید:

```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

### ۴. اجرای ربات

```bash
python game_center_bot.py
```

## 📖 نحوه استفاده

### دستورات

- `/start` - شروع ربات و نمایش منوی اصلی
- `/score نام_بازی امتیاز` - ثبت امتیاز بازی
  - مثال: `/score fifa 150`
- `/help` - نمایش راهنما

### منوی اصلی

ربات دارای منوی تعاملی با دکمه‌های زیر است:

1. **🎮 بازی‌ها** - مشاهده لیست بازی‌های موجود
2. **🏆 تورنمنت‌ها** - مشاهده و ثبت‌نام در تورنمنت‌ها
3. **📊 امتیازات من** - مشاهده امتیازات ثبت شده
4. **👤 پروفایل** - مشاهده اطلاعات کاربری
5. **📅 رزرو وقت** - رزرو زمان برای بازی
6. **🔔 اطلاع‌رسانی** - تنظیمات اطلاع‌رسانی
